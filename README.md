# Entitled

> Know what you qualify for. Know what you need. Know what's next.

A citizen-first public-benefits navigator built for Build What Moves India.

## What it does

Entitled helps citizens:

1. Discover benefits they may be eligible for
2. Understand why they appear eligible
3. Identify required documents
4. Complete a guided application
5. Submit a simulated application
6. Track applications

## Hackathon Prototype

This is an independent hackathon prototype.

Government integrations and submissions are simulated.
The project uses synthetic/demo data.

## Architecture

- Frontend: Next.js + TypeScript
- Backend: FastAPI + Python
- Database: SQLite/PostgreSQL
- AI: OpenAI API
